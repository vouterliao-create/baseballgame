# K-Zone 投打對決

右投 vs 右打的 3D 棒球投打對決網頁遊戲，電腦與手機皆可遊玩。

- 選擇先攻／先守、三・五・七・九局制、高中／職棒／大聯盟等級
- 進攻：移動黃色擊球框瞄準紅色進壘點，點擊／空白鍵（手機按「揮棒」）揮棒
- 防守：選球種（四縫線、曲球、縱向滑球、指叉球），瞄準好球帶投球

## 遊玩
開啟 GitHub Pages 網址，或直接用瀏覽器打開 `index.html`（需網路連線載入 3D 引擎、支援 WebGL）。

## 部署到 GitHub Pages
Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，儲存後約一分鐘即可在 `https://<帳號>.github.io/<repo>/` 遊玩。
